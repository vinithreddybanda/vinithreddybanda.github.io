# Vinith Reddy Banda

Personal portfolio built with Astro, React, TypeScript and Framer Motion.

## Stack

- Astro for static site generation and routing.
- React for the interactive command palette.
- Framer Motion for modal transitions.
- Geist and DM Mono typography.
- CSS for responsive layout and scroll-reveal motion.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the static site into `dist/` and deploys it to GitHub Pages whenever `main` is updated.
