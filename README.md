# Little World

A browser game set on one continuous spherical planet. Wander, meet residents, carry parcels, discover keepsakes, and customize your traveller.

Controls: WASD / arrow keys to walk, Shift to hurry, E to interact, drag to orbit the camera. On mobile, use the joystick, drag to look, and tap E.

The client is a static Three.js game hosted by GitHub Pages. No server or account is required for this single-player build. Multiplayer requires a separate authoritative room service and is not active here.

Three.js is used under its MIT license. No Messenger/Abeto artwork, models, music, or source assets are bundled.
