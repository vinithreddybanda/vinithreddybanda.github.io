# Vinith

A minimal React + Vite site, deployed with GitHub Pages.

## Typography standard

SF Pro Display is the single and only font family permitted across this entire website. Every element, including headings, body copy, labels, navigation, footer text, and form controls, must inherit `font-family: "SF Pro Display"`. Do not import, load, declare, or use any other font family or fallback font stack. Preserve typographic hierarchy through size, weight, line height, and letter spacing, not by introducing another typeface.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Pushes to `main` build the site and deploy the `dist` directory to GitHub Pages.
